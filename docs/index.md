# wtf

**A browser-like terminal for macOS and Linux.**

Tabs, split panes, workspaces, a side pane, SSH and Kubernetes tooling, secret
hiding and AI assistance, in one native app. A Go backend with AppKit and
SwiftTerm on macOS, and GTK 4, libadwaita and VTE on Linux.

## What's in it

- **Browser-style workflow:** [tabs and groups](manual/tabs.md), [split panes](manual/panes.md), [workspaces](manual/workspaces.md) and an [address bar with context badges](manual/context-badges.md).
- **SSH built in:** [hosts](manual/ssh-hosts.md), [keys](manual/ssh-keys.md), [tunnels](manual/ssh-tunnels.md) and [file copy](manual/ssh-files.md).
- **Kubernetes and cloud:** [contexts](manual/kube-contexts.md), [resources](manual/kubernetes.md), [AWS profiles](manual/aws.md) and [cloud secrets](manual/cloud-secrets.md).
- **Privacy first:** [hide secrets](manual/secrets.md) on screen and read the [privacy notes](manual/privacy.md).
- **AI when you want it:** [assistance](manual/ai.md) and [Claude Code / Codex agents](manual/agents.md).
- **Everyday tools:** [find](manual/find.md), [history](manual/history.md), [snippets and runbooks](manual/snippets.md), [recording](manual/recording.md).
